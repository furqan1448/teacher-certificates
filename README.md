# مشروع شهادة اجتياز

المشروع مجهز بصفحتين:
- دخول الإدارة: تسجيل الدخول بحساب Firebase ثم رفع ملف Excel دفعة واحدة.
- دخول المعلمة: رقم الجوال + كلمة المرور المكونة من 4 خانات ثم عرض الشهادة.

## ملف Excel
الأعمدة المتوقعة:
- م = كلمة المرور
- اسم المعلمة
- الفئة المناسبة للتدريس
- رقم الجوال

## مهم جدًا قبل النشر
النسخة الحالية فيها كود استيراد إداري يعمل مع Authentication، لكن تحقق المعلمة في `teacher.js` يستخدم Firestore مباشرة لأغراض الاختبار.
للإنتاج، استخدمي Cloud Function `verifyTeacher` الموجودة في `functions/index.js`، ثم اجعلي قراءة `teachers` ممنوعة للزوار بالكامل في Firestore Rules.

## إعداد Firebase
1. في Firebase > Project settings > App1 > SDK setup and configuration > Config.
2. ضعي القيم في `firebase-config.js`.
3. لا تضعي كلمة مرور الإدارة في الكود.
4. Firestore يجب أن يبدأ Production mode.

## نشر Cloud Functions
يتطلب نشر Cloud Functions تفعيل خطة الفوترة المناسبة في Firebase. لا تفعّلي ذلك قبل التأكد من الحاجة والتكلفة.

## الشهادة
الملف الحالي يحتوي على قالب شهادة HTML. لاستعمال صورة الشهادة الأصلية، أضيفي صورة الشهادة كخلفية أو ملف داخل المشروع وعدّلي `teacher.html` قبل النشر.
